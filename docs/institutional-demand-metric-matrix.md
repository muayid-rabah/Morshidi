# Institutional Demand V1 Metric Matrix

Policy version: **1.0**. The registry contains exactly **9** metrics. Every metric is descriptive, period-scoped, privacy-suppressed as a whole with its result, and derived only from resolved current intents.

| Metric ID | Metric Name | V1 Status | Input | Definition | Denominator | Zero-Credit Behavior | Privacy Rule | Missing-Data Behavior | Provenance | Limitations | Future Dependency |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `VALID_ACTIVE_INTENT_OWNER_COUNT` | Valid active intent owners | `SUPPORTED_V1` | Current valid submitted intents | Distinct owners with one resolved current valid intent in exact scope/period | None | Owner still counts | Withheld when scope suppressed | No current valid intent yields `INSUFFICIENT_DATA`, not an inferred institutional zero | Intent source and resolver versions | Participating owners only | Persistence/adoption evidence |
| `COURSE_INTENT_OWNER_COUNT` | Course intent owners | `SUPPORTED_V1` | Canonical current course sets | Distinct owners selecting exact canonical course; one owner/course/period maximum | None | Counts one owner | Withheld when scope suppressed | Unknown course/invalid intent excluded before aggregation | Intent plus catalog versions | Not enrollment or guaranteed demand | Actual-registration evaluation later |
| `COURSE_INTENT_SHARE_OF_VALID_INTENT_OWNERS` | Course share of valid-intent owners | `SUPPORTED_V1` | Course count and valid active owner count | Course intent owners divided by valid active intent owners in same exact scope/period | `VALID_ACTIVE_INTENT_OWNER_COUNT` | Included in numerator when selected | Withheld when suppressed | Omitted when denominator unavailable/zero | Derived from declared intent | Not share of all or eligible students | Authorized eligible-population contract |
| `TOTAL_DECLARED_COURSE_SELECTION_COUNT` | Declared course selections | `SUPPORTED_V1` | All canonical current course sets | Count of distinct owner/course selections in scope/period | None | Counts one selection | Withheld when suppressed | Invalid/review/superseded/withdrawn records excluded | Declared intent | One owner may contribute multiple selections | None for V1 |

| `REQUIREMENT_GROUP_INTENT_OWNER_COUNT` | Requirement-group intent owners | `SUPPORTED_V1` | Course-to-group plan mapping | Distinct owners selecting at least one course in exact normalized group | None | Counts owner/group | Withheld when suppressed | Missing group mapping makes affected metric unavailable | Intent plus plan/group version | Plan-version scoped | Cross-plan curriculum mapping later |

## View rules

`COURSE_BY_PLAN_DEMAND` groups course metrics by exact plan/version. `COURSE_GLOBAL_DEMAND` groups within one university/period and deduplicates owner/course pairs across included plans. These are views over the same metric registry, not additional metric types. No cross-university or cross-period view exists in V1.
